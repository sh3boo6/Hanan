# Kilo Configuration

This file configures Kilo for the Hanan project.

## Project Info

- **Name**: Hanan
- **Description**: دليل حنان - صفحة ويب帮助 المستخدم على الوصول للمواقع التي تهم المعلم او الإداري
- **Framework**: Nuxt 4
- **Package Manager**: pnpm

## Commands

| Command | Description |
|---------|-------------|
| `pnpm run dev` | Start development server |
| `pnpm run build` | Build for production |
| `pnpm run lint` | Run ESLint |
| `pnpm run typecheck` | Run TypeScript type checking |

## Notes

- This is a Nuxt application with Arabic RTL support
- Uses @nuxt/ui for UI components
- Uses VueUse for composition utilities
