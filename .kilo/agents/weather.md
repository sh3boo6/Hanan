# Weather Feature Agent

Agent for working on weather-related features in the Hanan app.

## Responsibilities

- Modifying `app/components/AppWeather.vue`
- Updating `composables/useWeather.ts`
- Updating `server/api/weather.get.ts`
- Ensuring lint and typecheck pass

## Guidelines

- Use VueUse for geolocation and permissions
- Keep Arabic RTL support
- Follow existing code style
- Test with `pnpm run lint` and `pnpm run typecheck`
